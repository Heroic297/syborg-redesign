# Syborg storefront redesigns

Two static, responsive storefront designs based on the supplied Syborg pages.

- `index-clean.html`: dark storefront (also available as `index.html`).
- `v2/index-clean.html`: light storefront (also available as `v2/index.html`).
- Each version includes product pages for the bottle and ampules, FAQ, and contact.
- Shared CSS, JavaScript, and original product photographs are in this folder.

Open either HTML file directly, or serve this folder with any static web server. Google Fonts supplies Barlow Condensed and DM Sans; local fallback fonts are included in CSS.

Purchase and support links open the official Syborg store. No simulated cart, payment form, or contact submission is included. Prices are carried over from the supplied source; final pricing and availability are confirmed at the store. Product warnings defer to the actual label. This is a design preview, marked noindex.

Checked in a browser at desktop and 390px mobile widths: images, horizontal overflow, mobile menu, product navigation, FAQ expansion, and console errors. Static validation covers all local page/asset links and anchors.

The original GitHub repository and public pages were not modified. To deploy to another static host, upload the contents of this folder together and preserve the folder structure.
